# عبدالرحمن الفرجاني — البورتفوليو الشخصي

موقع فعلي باستخدام React + TypeScript + Motion + Vite، بإخراج ثابت. العربية هي اللغة الافتراضية، مع حفظ اختيار اللغة محليًا.

## التشغيل

يتطلب Node.js 22.12+ أو إصدارًا أحدث متوافقًا مع Vite 7.

```sh
npm ci
npm run dev
```

افتح عنوان Local الذي يطبعه Vite (عادة http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

`dist/` هو مجلد النشر الثابت. لا تحتاج النسخة المبنية إلى خادم Node أو قاعدة بيانات. يجب تقديم الملفات عبر HTTP، وليس فتح index.html مباشرة من القرص. مسار الموقع الأساسي `/`، وصفحة نبض `/nabd/`، ولها ملف HTML فعلي في الناتج. لا توجد مفاتيح API أو خدمات خارجية مطلوبة لتشغيل الموقع.

## النشر على Render

المستودع عام على GitHub: `26abdlrhman/abdulrahman-portfolio`، ويحتوي `render.yaml` (Blueprint) يعرّف موقعًا ثابتًا باسم `7am7am` — العنوان الناتج `https://7am7am.onrender.com`. الإعدادات: أمر البناء `npm ci && npm run build` ومجلد النشر `dist`، مع إعادة النشر تلقائيًا مع كل commit إلى `main`. إصدار Node محصور في `>=22.12.0 <25` عبر `engines` في `package.json` (متطلب Vite 7). النشر اليدوي البديل: `npm run build` ثم رفع محتوى `dist/` على أي استضافة ثابتة.

## ما نُفّذ

- افتتاحية بصورتك المعالجة بخلفية شفافة، مكعب مبني بـCSS، طبقات parallax، واستجابة خفيفة للمؤشر.
- مشهد تمرير مثبت: ستة عناصر متفرقة تنتظم وتظهر بينها الروابط خلال خمس خطوات. Motion useScroll + useSpring + useTransform؛ التمرير طبيعي وقابل للعكس.
- ثلاثة مشاريع في قسم الأعمال، ولكل منها صفحة حالة مستقلة بمسار ثابت:
  - **نبض** `/nabd/`: صورتان من الواجهات الأصلية ببيانات تجريبية، وشرح للمنظومتين والمزامنة والماليات.
  - **لونا ستور** `/luna/`: متجر إلكتروني، مع قسم مخصص لرحلة الدفع عبر MyPay.ly (سلة، بيانات الطلب، جلسة دفع، بوابة، تحقق من الرمز، وويب هوك بتوقيع HMAC-SHA256) وقسم لسهولة التعامل (بلا حساب، عربي أولاً، حالات واضحة، لوحة تحكم بسيطة)، ثم لقطات واجهة حقيقية ببيانات تجريبية بنمط لقطات نبض (وصف لكل صورة ورابط تكبير).
  - **نظام إدارة الكافيه** `/cafe-pos/`: نقطة بيع ونوبات ومديونية ومصروفات وتقارير، مع تطبيق موبايل وترخيص يُدار عن بُعد، ولقطات شاشة البيع والمديونية والتقارير والمصروفات بالنمط نفسه.
- انتقال مشترك لعرض المشاريع باستخدام View Transitions في المتصفحات الداعمة، مع تنقل عادي كبديل.
- محتوى عربي وإنجليزي، RTL/LTR، قائمة هاتف، أقسام قدرات قابلة للفتح، وروابط تنقل مباشرة.
- قط Rive الأصلي: idle، استجابة للمرور والتركيز، تفاعل الفم عند الضغط، إخفاء وإظهار. يتوقف خارج الشاشة ومع تقليل الحركة.
- تقليل الحركة عبر إعداد النظام أو زر التذييل، وحالة ثابتة تعرض جميع خطوات المنهجية.
- نموذج طلب مشروع يفتح تطبيق البريد مع تفاصيل الطلب، وروابط البريد وواتساب.
- الخطوط والصورة وRive/WASM محلية. صورة WebP نحو 124KB، ويحمّل القط وملفه التنفيذي فقط قرب قسم التواصل.

## ما يحتاج معلوماتك

1. مراجعة تطابق الوجه في الصورة المعالجة. حُفظت صورك الأصلية دون تعديل. الطول 160 سم استخدم كقيد للتناسب البصري، وليس قياسًا هندسيًا مضمونًا للصورة.
2. التواصل مربوط بالبريد wahj200013@gmail.com وواتساب 0927592771 بصيغة ليبيا الدولية. النموذج يفتح تطبيق البريد؛ لا توجد خدمة إرسال خلفية.
3. راجع صياغة نبض. بُنيت من مصدر المنظومتين؛ اللقطات من القوالب الأصلية ببيانات تجريبية. حالة الإطلاق والنتائج الكمية ليست محل ادعاء في الموقع.
4. راجع صياغة لونا ستور. رحلة الدفع وسهولة التعامل مبنيتان من قراءة كود المشروع (app.py: دوال MyPay.ly، مسار checkout، ويب هوك، فاتورة). أسماء طرق الدفع المعروضة (بطاقات مصرفية، إدفعلي، يسر باي، صحاري باي، مصرفي باي) هي ما تعرضه واجهة الدفع الأصلية؛ صفحات المشروع مُصوَّرة بلقطات شاشة حقيقية من تشغيل معزول ببيانات تجريبية (قاعدة محلية، بلا اتصال بقاعدة الإنتاج أو بوابة الدفع).
5. راجع صياغة نظام إدارة الكافيه. المزايا ومسار الترخيص عن بُعد مبنيتان من قراءة كود المشروع (app.py، FullServer.py، Server/server، Server/client، تطبيق Flutter). لقطات الشاشة من تشغيل معزول بقاعدة بيانات تجريبية نظيفة؛ لا تُعرض بيانات عملاء أو أرقام ترخيص حقيقية.
6. المشاريع الأخرى تضاف بعد تزويدنا بتفاصيلها؛ لا توجد مشاريع وهمية.

## هيكل الملفات

- `src/App.tsx`: مكونات الصفحة الرئيسية وصفحات الحالات الثلاث (نبض، لونا ستور، نظام إدارة الكافيه)، والنصوص الثنائية.
- `src/content.ts`: بيانات القدرات وخطوات العمل ووسائل التواصل.
- `src/Pet.tsx`: دمج القط وتحكم التفاعل والحركة.
- `src/style.css`: الهوية، التكوين، التجاوب، وتقليل الحركة، وتنسيقات بطاقات وصفحات المشاريع الثلاثة.
- `src/fonts.css`: مجموعتا الخط العربي واللاتيني المطلوبتان فقط.
- `src/devAudit.ts`: قياسات محلية اختيارية عند `?audit` في وضع التطوير؛ لا تُضمّن في بناء الإنتاج.
- `public/assets/`: الصورة المعالجة، القط الأصلي، ملف WASM، لقطتا نبض، وصور منتجات لونا ستور المضغوطة، إضافة إلى لقطات الشاشة الحقيقية لواجهتَي لونا ستور ونظام إدارة الكافيه (مأخوذة من تشغيل معزول ببيانات تجريبية).
- `scripts/postbuild.mjs`: إنشاء مسارات الصفحات الثابتة الثلاثة و404.
- `ASSET-NOTES.md`: المصدر والترخيص وطريقة معالجة الصورة.
- `QA.md`: نطاق الاختبارات وحدود القياسات.

## الإضافة والتعديل

تُجمع بيانات الخدمات والخطوات في مصفوفات لتسهيل الإضافة. `Work` يعرض بطاقات المشاريع، و`ProjectDetail` يوجّه من المسار إلى صفحة الحالة (`Project` لنبض، `LunaCase` لونا ستور، `CafeCase` للكافيه). عند إضافة مشروع مستقل جديد، أضف بياناته ومكوّن صفحته ومساره إلى سكربت postbuild. حافظ على المسارات الأساسية عند النشر إلى مجلد فرعي أو اضبط base والروابط معًا.
